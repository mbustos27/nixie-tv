# Spanish release notes

Nixie for TV's release notes are in English, on
[its releases page](https://github.com/mbustos27/nixie-tv/releases). This file holds no versions.

It stays because the build copies it into debug builds (`changelogAsset` in `app/build.gradle.kts`). When Glacier's
updates are merged, keep this version of the file.

Glacier's Spanish release notes, up to Glacier 0.10.1 (the version Nixie for TV is based on), are in
[Glacier's repository](https://github.com/Glacier-Jellyfin/glacier-androidtv/blob/main/CHANGELOG.es.md).
